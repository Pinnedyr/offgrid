## 🌐 What is OFFGRID?

OFFGRID is a simple, lightweight browser start page built to make browsing more accessible and convenient.

Designed primarily with school Chromebooks in mind, OFFGRID provides a straightforward starting point for exploring the web without unnecessary features, complicated installations, or additional software.

Finished your assignment early? Waiting for the next lesson? OFFGRID gives you a simple place to start browsing.

## ✨ Features

- **Chromebook-friendly** – Designed with school Chromebooks in mind.
- **Lightweight** – Built around a standalone HTML file.
- **No installation required** – Simply open the HTML file in a browser.
- **Simple interface** – Clean, minimal design with easy navigation.
- **Dark design** – A comfortable dark interface.
- **Responsive** – Designed to work across different screen sizes.
- **Easy to use** – Get started without complicated setup.

## 🚀 Getting Started

Once downloads become available:

1. Visit [offgrid.wtfq.online](https://offgrid.wtfq.online).
2. Download the OFFGRID HTML file.
3. Open the downloaded file in your browser.
4. Start exploring!

No installer or additional software is required.

## 🔒 Privacy & Security

OFFGRID is designed to be lightweight and straightforward.

A few things to keep in mind:

- OFFGRID does not disable exam mode but it give access to the whole internet.
- School-managed devices and networks may still monitor browsing activity.
- Website availability depends on your browser, device and network.
- OFFGRID does not guarantee anonymity or unrestricted access.
